支持

净界 PureBlock · iPhone / iPad

如何在 Safari 中启用净界？

打开系统「设置」→ 向下找到「Safari」→「扩展」→ 轻点「净界」→ 打开开关，并选择「允许在所有网站」。回到 Safari 后刷新页面即可。

为什么有些广告还在？

Safari 内容拦截器只能拦截规则列表中的域名和元素。部分广告来自第一方域名，或与正常内容使用同一域名，无法可靠拦截。你可以在 Safari 的扩展设置中临时关闭净界。

网站显示异常怎么办？

部分网站依赖被拦截的脚本或 Cookie 横幅。可在 Safari 地址栏左侧的「aA」菜单 →「管理扩展」中关闭净界，或仅在该网站关闭。

会上传我的浏览记录吗？

不会。净界不联网，规则在设备本地运行。详见隐私政策。

如何申请退款？

App Store 购买由 Apple 处理。请访问 reportaproblem.apple.com 申请退款。

联系开发者：请通过 App Store 产品页的「App 支持」链接，或在 GitHub 仓库 提交 issue。请附上 iOS 版本、Safari 版本和问题网站地址（如方便）。

Support

PureBlock · iPhone / iPad

How do I enable PureBlock in Safari?

Open Settings → Safari → Extensions → tap PureBlock → turn on the switch and choose “Allow on All Websites”. Return to Safari and reload the page.

Why do some ads still appear?

Safari content blockers can only block domains and elements in their rule list. Some ads are served from the same domain as the page content and cannot be reliably blocked. You can temporarily disable PureBlock in Safari’s extension settings.

A website looks broken. What should I do?

Some sites depend on scripts or cookie banners that are blocked. Use the “aA” menu in Safari → Manage Extensions to turn PureBlock off for that site or entirely.

Do you upload my browsing history?

No. PureBlock has no network access and runs every rule locally. See the Privacy Policy.

How do I request a refund?

App Store purchases are handled by Apple. Visit reportaproblem.apple.com to request a refund.

Contact: Use the App Support link on the App Store product page, or open an issue in the GitHub repository. Include your iOS version, Safari version and the site URL if possible.
