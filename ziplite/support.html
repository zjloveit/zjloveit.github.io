支持

轻压 ZipLite · iPhone / iPad

导入的文件在哪里？

压缩包保存在「轻压/Archives」。打开系统「文件」App → 我的 iPhone → 轻压 即可查看、导入或导出。

支持哪些格式？

解压：RAR、7z、ZIP、TAR、GZ、BZ2、XZ、ZST、LZ4 等常见格式；创建：ZIP。具体支持取决于压缩包使用的编码。

支持加密压缩包吗？

当前版本暂不支持带密码的压缩包。遇到加密包会给出提示，不会写入不完整的文件。

解压失败怎么办？

请确认压缩包完整、未加密，且文件名没有异常路径。仍失败时，请通过下方支持渠道反馈压缩包格式和错误提示。

会上传我的文件吗？

不会。轻压没有网络权限，所有处理都在设备本机完成。详见隐私政策。

联系开发者：请通过 App Store 产品页的「App 支持」链接，或在 GitHub 仓库 提交 issue。提交时请附上 iOS 版本、压缩包格式和错误提示，不要上传包含隐私的文件。
English

Support

ZipLite · iPhone / iPad

Where are my imported files?

Archives are stored in ZipLite/Archives. Open Files → On My iPhone → ZipLite to browse, import or export them.

Which formats are supported?

Extract RAR, 7z, ZIP, TAR, GZ, BZ2, XZ, ZST, LZ4 and more; create ZIP when needed. Support depends on the codecs used inside the archive.

Can I open password-protected archives?

Encrypted archives are not supported yet. ZipLite will show a message and will not leave incomplete files behind.

What if extraction fails?

Make sure the archive is complete, unencrypted and does not contain unsafe paths. If it still fails, contact support with the archive format and error message.

Are my files uploaded?

No. ZipLite has no network access and processes everything on device. See the Privacy Policy.

Contact: Use the App Support link on the App Store product page, or open an issue in the GitHub repository. Include your iOS version, archive format and error message. Please do not upload private files.
